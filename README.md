Why I built this

when I started doing appointment setting for others
I knew how to get leads
but I had no tool to sort them

I would pull lists from Apollo and other tools
then sit for hours figuring out
who is actually in my niche
who my client can actually help

every list needed cleaning
before I could use it for outreach or automation

so I built LeadIQ

drop in your leads
it scores them against your ICP
you see the exact profiles worth targeting
by the title on their profile

easy to use
anyone can use it for themselves

How it works

drop a CSV from LinkedIn Apollo or Phantombuster
or try it with the sample data
check the columns look right
set your own keywords and weights
pick the minimum score you care about
hit score my leads
download the enriched CSV with scores and matched keywords

Your data

everything runs in your browser
no server no upload no account
your data never leaves you

Use it

open index.html in any browser
or use the live link below
thats it
